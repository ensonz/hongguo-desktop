# GPUI 壳点击行为复核清单

GPUI 壳的功能代码已全部落地（dev 分支至 `1eb0152`），渲染层已用进程内截图逐项验证。剩下的**点击行为**需要在真实壳里人工过一遍——本清单按操作顺序编排，每项含操作步骤与预期结果。

## 准备

```bash
cargo run -p hongguo-gpui      # 或 make gpui
```

启动后自动恢复上次播放。侧栏自上而下：首页 / 排行榜 / **登录**。

## 登录（后续各项的前提）

1. 侧栏点「**登录**」→ 居中面板弹出；
2. 输手机号（11 位）→ 点「**发送验证码**」→ 状态行提示发码成功；
3. 收到短信后输验证码 → 点「**登录**」→ 提示「登录成功：<昵称>」；
4. 侧栏项变为「**退出登录**」即生效（评论/删除/预约/点赞此时可用）。

异常：提示「风控需短信上行验证」→ 按短信提示回复短信后点「**重试登录**」。

## 复核项

| # | 操作 | 预期 |
|---|------|------|
| 1 | 大屏控制条**喇叭图标**悬停 | 上方弹出竖向音量滑杆；拖到 0 = 静音，移开收起 |
| 2 | 播放中观察**弹幕** | 弹幕横向滚动；`[微笑]` 类代码渲染成表情图；控制栏齿轮可调透明度/字号/密度/区域 |
| 3 | 点右缘**💬（计数）**开评论面板 | 列表带**圆形头像**（远程图；无图退回首字）；点赞红心 ±1；行内「回复」展开输入框 |
| 4 | 评论行「**回复**」→ 底部输入框旁**笑脸按钮** | 上拉 8 列表情网格；点格子把 `[名字]` 插入光标处且**面板不关**；点外部收起 |
| 5 | 发一条评论 → 自己那行出现「**删除**」 | 点删除 → 确认浮层 →「删除」→ 行消失 + 「评论 · N」减一；自己的**回复**同理（父评论「展开 N 条回复」减一） |
| 6 | 控制条「**下载**」→ 入队几集 | running 行有「**暂停**」→ 点击变「已停止」；「**重试**」→ 回到队列续跑；面板右上 **×** 正常收起 |
| 7 | 控制条「**选集**」→ **系列剧** tab | 当前季红框「播放中」；未上线季灰卡「即将上线」+「🔔 预约」→ 点后变「已预约」；可播季点击直接换剧 |
| 8 | 控制条 **PiP 图标**（⛶ 左侧） | **同一个窗口**缩成 480×270 落到屏幕右下角，播放不中断，紧凑控制条（播放/上下集/倍速/静音/隐身/钉住/放大/关闭）；点「钉住」窗口置顶；「放大」还原原位原尺寸；Esc 同放大；「✕」暂停并还原 |
| 9 | 点右缘**红心（点赞数）** | 未登录提示需登录；登录后红心变红 + 计数 ±1（乐观），失败回滚 |

## 已知边界

- 小窗的「钉住」是窗口级会话态，退出小屏不清除（与 Tauri 一致）。
- macOS 壳的小窗只缩放不落位/不置顶（Win32 FFI 限 Windows）。
- MFA 风控走「重试登录」手动路径（Tauri 版的自动轮询尚未移植）。
- 表情选择器插入后若光标不在输入框末尾，插入位置以真实光标为准。

发现不符项：记录「哪一项、点了什么、看到什么」，反馈后按项修复。
